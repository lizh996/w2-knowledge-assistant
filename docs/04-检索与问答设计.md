# 检索与问答设计

> **文档来源**：V1→V3 迭代中逐步完善（retrieve.py/generate.py，实测阈值）


> 用户提问到出答案，经历 8 步可观测链路（retrieve.py + generate.py + api.py 编排）。

## 一、检索链路（8 步 trace）

```
question_input → reject_check → dense_retrieval → sparse_retrieval
→ rrf_fusion → rerank → context_organize → generation → citation
```

| 步 | 做什么 | 说明 |
|---|---|---|
| 问题输入 | 收 question + history | 多轮追问拼接历史 |
| 拒答判断 | 双阈值判库内/库外 | dense≥0.445 或 sparse≥0.20 放行 |
| Dense 检索 | 语义向量查库 | BGE-M3 dense，1024 维余弦 |
| Sparse 检索 | 关键词查库 | BGE-M3 sparse，IDF 权重 |
| RRF 融合 | 两路按排名融合 | `1/(60+rank)`，粗排 15 条 |
| 精排 | cross-encoder 打分 | bge-reranker 重排取 5 |
| 上下文组织 | 去噪/去重/预算 | 负分过滤 + embedding 去重 + token 2000 |
| 生成 | DeepSeek 组织答案 | 带页码 + 引用 = 真进 LLM 的块 |

## 二、复合检索（retrieve.py）

### 查询改写（V3）
```
口语问题 → 规范术语（LLM，fail-open：失败回原问题）
带开关 QUERY_REWRITE_ENABLED + 缓存
例子："回收装置有啥功能" → "回收装置功能 设备用途"
```

### Dense + Sparse + RRF
```
为什么两路：dense 抓语义（换说法也能中）、sparse 抓精确（数字/标准号）
为什么 RRF 不用分数融合：dense 余弦(-1~1) 与 sparse 内积(不封顶) 量纲不同
RRF 分 = 1/(60+rank)，融合后取 top15 粗排
```

### 精排（V3，RERANK_ENABLED 开关）
```
粗排 15 条 → bge-reranker cross-encoder 逐条打相关度分 → 取 top5
为什么精排：多文档噪声大，真答案常排 7+，精排救回（#4"重复性要求"实测救回 rank2）
```

## 三、拒答判定（双阈值，实测校准）

| 路 | 阈值 | 依据 |
|---|---|---|
| dense | 0.445 | 微调后实测：库内 min 0.485 / 库外 max 0.406 |
| sparse | 0.20 | 微调后实测：库外 max 0.173 |

> 判定：dense 高分 **或** sparse 高分任一满足即放行（语义 + 精确词互补）。
> ⚠️ 换模型后必须重新校准阈值（向量空间变了，分数分布偏移）——踩坑记录。

## 四、生成（DeepSeek）

```
输入：改写后问题 + 组织后的证据块
输出：答案 + 页码引用（[GB_T_17623-2026.pdf · 第 7 页]）
诚实原则：citations 只列真正进 LLM 的块
库外问题：refused=true → "知识库依据不足"（不编造）
```

## 五、评测指标

| 指标 | 说明 | 最新实测 |
|---|---|---|
| Recall@5 | 正确答案进前 5 的比例 | 0.9167（12题）/ 0.94（350条 E1）|
| MRR | 首正例排名倒数均值 | 0.6625→0.6694（V1→V3）|
| 拒答准确率 | 库外正确拒绝 | 100% |
