# 离线到在线 · 工程化复盘

> **文档来源**：项目收尾复盘（git 记录 + 踩坑整理）


> 从"能跑"到"能交付"踩过的坑 + 工程化经验 + 答辩演进故事。

## 一、核心教训（按环节）

| 环节 | 踩的坑 | 教训 |
|---|---|---|
| 模型并发 | 3 任务并发加载 2GB BGE-M3 → meta tensor 崩溃 | 模型必须单例 + 加锁 |
| 精排 | rerank 通道是假的（复制 RRF 分）| 必须真调 cross-encoder；用检索测试台验证 |
| 微调 | InfoNCE 把"自身"当负例 → 评测 0.88→0.15 | loss 收敛≠成功；必须评测；对角线排除 |
| 换模型 | 拒答阈值失灵（该答拒/该拒答）| 换模型必须重新校准阈值（向量空间变了）|
| 启动 | cmd set 变量尾空格 → 路径找不到 | set VAR=值&& 不留空格 |
| 预设问题 | 常用问题从旧项目搬 → 全超纲答不出 | 预设示例必须用库内验证过的问题 |
| 服务 | 长跑后卡死（502/CLOSE_WAIT）| 讲解答辩前先健康检查/重启 |
| 评测 | Qdrant 单进程锁 | 评测前停服务 |

## 二、工程化 Checklist

```
□ git 提交留痕（每功能一次，12 commits）
□ 评测驱动：改任何检索环节先立基线再对比
□ 开关控制：RERANK_ENABLED / QUERY_REWRITE_ENABLED（可回退）
□ 模型版本化：原模型不覆盖，BGE_MODEL_PATH 切换（可回滚）
□ 诚实：引用=真进 LLM 的块；库外不编造
□ 可观测：trace 8 步 + 检索测试台四路 + 系统健康三查
□ 数据落地：SQLite（任务/评测）+ Qdrant（知识）
□ 一键部署：bat 启动 + /docs 自动文档 + 健康检查
```

## 三、演进故事（答辩用）

> 我先立评测集当尺子，V1 跑通最小闭环（recall 0.9167）；V2 发现"答不出为什么"——加 trace、加复合检索，让过程可信可见；V3 多文档噪声大，加精排和改写，MRR 0.6625→0.6694；最后做嵌入模型微调（W3），800 条数据 LoRA 训练，264 题干净集评测 Recall@5 base 0.890 → E1 0.928（+3.8pp，剔除 86 条 source=train-query 背题）；E2 0.924（-0.4pp，保留 E1 不部署），接入系统后重新向量化、校准阈值，全链路回归通过——**每一步都有 git 记录、评测数据、和踩坑归因**。
