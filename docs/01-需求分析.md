## 一、业务目标

1. **知识库**：把 3 份变压器国标（正文 + 表格 + 公式 + 图）变成可检索、可问答、可追溯的知识库（88 块）。
2. **问答服务**：运维人员现场提问 → 带页码答案 + 证据引用 + 无依据拒答——"查得到、信得过、不编造"。
3. **构建服务**：上传新 PDF → 异步六步管线（解析→清洗→分块→向量化→入库→评测）→ 实时看进度、可管理知识库。
4. **工程落点**：评测驱动迭代（V1→V3 + 嵌入模型微调），每个版本指标可量化、可回滚。

## 二、功能需求（FR，对齐实现）

| # | 需求 | 优先级 | 说明 | 实现落点 |
|---|---|---|---|---|
| FR1 | 文档解析 | 高 | **双通道**：fitz 秒级（正常 PDF）+ MinerU GPU（乱码/扫描兜底）| extract.py / pipeline._mineru_parse |
| FR2 | 复杂元素提取 | 高 | 表格（原子块）+ 公式 + 图（标引展开）→ 语义块 | pipeline.build_chunks |
| FR3 | 数据清洗 | 高 | 文本规范化 + 乱码检测（_looks_garbled + 整本门槛）| pipeline.clean_pages |
| FR4 | 分块 | 高 | 结构分块 + 语义类型分类 + **≤512 token** + 页码不跨页 | pipeline._split_by_tokens |
| FR5 | 向量化 | 高 | BGE-M3：**dense(1024) + sparse** 双向量；单例+锁防并发崩溃 | retrieve._get_model + pipeline.vectorize_chunks |
| FR6 | 向量库存储 | 高 | Qdrant embedded；每文档独立集合；payload 元数据（页码/来源/语义类型/关键词）| retrieve / pipeline.upsert_collection |
| FR7 | 复合检索 | 高 | dense+sparse 双路 → **RRF 融合**（粗排 15）| retrieve._query_rrf_collections |
| FR8 | 查询改写 | 中 | 口语 → 术语（LLM，fail-open，开关可回退）| retrieve._rewrite_query |
| FR9 | 精排 | 高 | bge-reranker cross-encoder → 取 5（开关 RERANK_ENABLED）| retrieve._get_reranker |
| FR10 | 上下文组织 | 高 | 负分过滤 + embedding 去重 + token 预算 → 真证据 | retrieve._organize_context |
| FR11 | 问答 | 高 | 八步链路 + **拒答判断**（双阈值）+ 多轮历史 + 带页码答案 | api.ask |
| FR12 | 无依据拒答 | 高 | 库外问题 refused=true（dense≥0.445 或 sparse≥0.20 放行，实测校准）| retrieve.reject 判定 |
| FR13 | 文件上传 | 高 | 上传 PDF → 秒回 task_id → **异步构建**（线程池不阻塞问答）| api.upload |
| FR14 | 构建过程展示 | 高 | 任务状态机六步 + **SSE 实时** + 轮询兜底 + SQLite 刷新不丢 | api.pipeline/events |
| FR15 | 知识库管理 | 中 | 文档列表/删除（内置保护）+ 分块查看 | api.documents/chunks |
| FR16 | 检索调试 | 中 | 只检索不生成，四路结果（dense/sparse/rrf/精排）| api.retrieve-test → retrieve_debug |
| FR17 | 系统健康 | 中 | 三查体检（qdrant/生成/精排）+ 评测历史 | api.admin/health · eval-history |
| FR18 | 评测 | 高 | recall@5/MRR/拒答率；版本集 12 题 + 微调集 350 条 | eval/ 脚本 |

## 三、非功能需求（NFR，带实测标准）

| # | 需求 | 说明 |
|---|---|---|
| NFR1 | 可溯源 | 答案必须带页码；引用 = 真正进 LLM 的块（诚实化）|
| NFR2 | 不编造 | 库外问题明确"依据不足"；拒答实测 100%（10/10）|
| NFR3 | 可评测 | recall@5 / MRR / 拒答率可量化；版本集 12 题、微调集 350 条（大样本）|
| NFR4 | 原子性 | 构建失败不产生半成品库（集合整体 upsert）|
| NFR5 | 可回滚 | 原模型不覆盖；BGE_MODEL_PATH 开关切换微调/原模型 |
| NFR6 | 响应 | 问答秒级（8 步实测 <10s）；上传异步不阻塞问答 |
| NFR7 | 可复现 | 同文档重复构建结果一致（SQLite 任务记录）|
| NFR8 | 不过度设计 | 单机教学版：线程池 + SQLite + embedded Qdrant + 原生 HTML/JS |
| NFR9 | 可迁移 | Qdrant embedded → 生产 API 只改连接（规模小无需 Milvus）|

## 四、范围边界

**范围内**：3 份内置变压器国标 + 上传新 PDF；文本/表格/公式/图解析问答；带页码溯源 + 拒答；后台管理/调试/评测；嵌入模型微调（W3 已完成）。

**范围外（后续版本）**：多租户/移动端/父子与递归分块/Qdrant→Milvus（>100 万向量才换）/其他语种。
